# Jermey@Web

A dark, mobile-first Android search app. Search Google Web, Images, Videos, and News without an API key.

## Build
Push to `main` or run the **Build Jermey@Web APK** workflow from the Actions tab. Download the `Jermey-Web-debug-apk` artifact from the completed run.

## App
- Android WebView shell with a responsive HTML/CSS/JS interface
- Google search modes: Web, Images, Videos, News
- Local recent-search history
- No API key, backend, or account required

The app requires internet access to load Google search pages.
